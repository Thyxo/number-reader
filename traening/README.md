# Number Reader – træning

Statisk side til desktop: flere iPhone-rammer med appens numeriske blok. Skriv ord med bogstaver og/eller tal (eller tryk på tasterne), og peg appens kamera mod skærmen.

- `t9.js` og `words.js` er kopier fra `src/` (ret dér og kopiér). Ingen build.
- Vercel: nyt projekt → samme GitHub-repo → **Root Directory: `traening`**, Framework: Other.
